## 🚀 Cara Menjalankan Proyek Secara Lokal
1. Clone repositori ini:
   ```bash
   git clone https://github.com/muhammadgunturcahyadiputra-boop/portfolio-ameliorer.git
   ```
2. Masuk ke direktori proyek:
   ```bash
   cd portfolio-ameliorer
   ```
3. Buka file `index.html` langsung di browser Anda, atau gunakan Live Server (VS Code / Python):
   ```bash
   python -m http.server 3000
   ```
4. Akses melalui browser di `http://localhost:3000`.
